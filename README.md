# R.C. Pica — mājaslapa (latviešu valodā)

Statiska vietne: `index.html` (sākumlapa) un `rezervacija.html` (pieteikums ballītei/festivālam).

## Kā aizpildīt saturu
Viss, ko var mainīt, ir failā `site.js`: tālruņi (`phones`), e-pasts, atrašanās vieta, darba laiki, ēdienkarte, bildes, video.
- Bildes: ieliec `assets/photos/`, ieraksti `photos` sarakstā.
- Video: lejupielādē no Instagram un saglabā kā `assets/video/pica.mp4` (vai norādi `instagramReel` saiti).
- `bookingEmail`: uz šo adresi nonāk pieteikumi no formas.

Atver `index.html` pārlūkā vai publicē ar GitHub Pages.
